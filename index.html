Précision & paris

Synchronisation téléphone / PC

Mêmes paris, même journal, mêmes saisies (gardien choisi, absents, compo collée, cotes tapées) et mêmes réglages sur tous tes appareils, par un dépôt GitHub privé à ton nom. Le jeton reste dans ce navigateur : jamais exporté, jamais synchronisé.

Mise en place (une fois, environ 10 minutes)
  1. Crée un compte sur github.com (gratuit) si tu n'en as pas.
  2. Appli en ligne : bouton « New » → nom nhl-value-board, Public → « Create repository » → « uploading an existing file » → glisse les fichiers de l'appli en ligne (index.html, manifest.webmanifest, sw.js et les trois icônes) → « Commit changes ». Puis Settings → Pages → Branch : main, dossier / (root) → Save. Une à deux minutes plus tard, elle est à l'adresse https://ton-pseudo.github.io/nhl-value-board/.
  3. Données : « New » → nom nhl-donnees, Private, coche « Add a README file » → « Create repository ».
  4. Jeton : ta photo (en haut à droite) → Settings → Developer settings → Personal access tokens → Fine-grained tokens → « Generate new token ». Nom : NHL synchro ; expiration : 1 an ; Repository access : « Only select repositories » → nhl-donnees ; Permissions → Repository permissions → Contents : Read and write → « Generate token » → copie-le (il commence par github_pat_).
  5. Ici, sur le PC : ton pseudo, nhl-donnees, le jeton et l'adresse de l'appli en ligne → « Enregistrer et synchroniser ». Le premier appareil envoie tout son historique.
  6. Téléphone : « Relier un autre appareil » → scanne le QR code → « Relier » → dans Chrome, menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
  7. Sur le PC aussi, tu peux installer l'appli en ligne (icône d'installation dans la barre d'adresse d'Edge ou de Chrome) et la relier avec « Copier le lien » : une seule version à suivre.

Le jeton expire au bout d'un an : l'outil le dira (« jeton refusé »), il suffira d'en créer un nouveau. Un dépôt public est refusé : tes paris n'y seraient plus privés.

Pré-saison

Pour vérifier la chaîne en conditions réelles avant l'ouverture : effectifs, arrivées, compositions, cotes. Aucun pari conseillé, rien n'entre dans le bilan de précision. Les résultats de pré-saison n'expliquent qu'environ 2 % des écarts de saison régulière : ils ne servent qu'à estimer le temps de glace des recrues.

Auto-test du moteur
Contrôle les invariants du modèle et signale tout mécanisme inactif.

Le moteur enchaîne : stats de club (saison) → game logs joueur pour les fenêtres 7/14/30 j → multiplicateur de forme amorti et borné → buts attendus par équipe (alignement + saison, ajustés défense adverse et gardien annoncé) → tirs cadrés simulés Poisson, conversion binomiale contre le SV% effectif du gardien → prolongation puis tirs de barrage si égalité. Les probabilités sont un modèle, pas une vérité : compare toujours au marché avant de conclure à un edge.
